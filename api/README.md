# Requirements Builder API

Express + TypeScript API scaffold with Mongoose models for the requirements builder project.

Quick start:

````bash
cd api
npm install
cp .env.example .env
# set MONGO_URI in .env
npm run dev

Seeding data

To create sample data run:

```bash
npm run seed
````

This will create sample `applications`, `users`, `tags`, and a few `requirements` if they do not already exist.
